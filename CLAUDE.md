# Swept Cleaning website – notes for Claude

Next.js 16 (App Router) + Tailwind 4 site for Swept Cleaning (residential cleaning, Brisbane / Logan / Gold Coast / Tweed Heads). Business facts live in `src/lib/site.ts`, services in `src/lib/services.ts`, suburbs in `src/lib/suburbs.ts`.

## "Create a new Cleaning Guide titled …"

Follow `docs/CLEANING-GUIDES.md` exactly:

1. Write original, accurate content in Australian English. No invented stats, reviews or guarantees, and nothing copied from other sites. Include prices or rates only when the owner asks, sourced and dated. No promotions.
2. Create `src/content/guides/<slug>.ts` exporting `const guide: Guide`. Set a `description` of 110–160 characters, a `metaTitle` ending "| Swept Cleaning" if `${title} | Swept Cleaning` would be over 60 characters, and a `sources` list for every fact or price taken from elsewhere.
3. Register it in `src/content/guides/index.ts`.
4. Add internal links to the relevant service pages (`services: [...]` plus inline `[text](/services/...)` links), and to other guides or area pages where natural. For a location-specific guide, set `areas: [...]` so it appears on that area's suburb pages. Never make per-suburb copies.
5. Don't create custom page layouts. The template at `src/app/cleaning-guides/[slug]/page.tsx` handles every guide.
6. Build, run `scripts/smoke.cjs`, `scripts/seo-check.cjs` and the SEO audit (`scripts/seo-audit.cjs` + `scripts/seo-analyse.py`), then commit and push.

The sitemap, `llms.txt`, structured data, related guides and the guides listing update automatically.

## Other conventions

- Brand: coastal blue #527C91 (primary – buttons, links, icons, logo mark), dark navy #061B49 (headings/text), white, subtle background #F3F8F9, light accent #E5EFF2 – as tokens in `src/app/globals.css` (token names are historical: `violet` = coastal blue, `violet-ink` = deeper blue for small text on tinted backgrounds, `lavender` = subtle background, `lilac` = light accent). No purple anywhere. Mostly white pages, no large coloured panels or heavy gradients. Logo files are in `public/brand/` (`swept-logo`, `swept-logo-white` for the navy footer, `swept-mark`).
- Every page's metadata goes through `pageMeta()` in `src/lib/seo.ts`.
- Production domain: `https://sweptcleans.com.au` (non-www), set once in `src/lib/siteConfig.ts`. Build URLs with `siteUrl()` / `absoluteUrl()` from `src/lib/site.ts` – never hard-code the domain. Reference the business entity with `orgRef()` from `src/lib/schema.ts` – never declare a second business entity. Only production deployments are indexable.
- BookingKoala is embedded in two places only: the customer login (`src/components/BookingKoalaEmbed.tsx` + embed.js, `/login`) and the lead enquiry form on `/quote` (`src/components/BookingKoalaLeadForm.tsx` + iframeResizer.min.js; see `docs/BOOKINGKOALA-LEAD-FORM.md`; `NEXT_PUBLIC_QUOTE_FORM=native` shows the site's own form instead). Never load its scripts anywhere else. The site's own forms (the native `/quote` form with Residential/Commercial tabs, the homepage/suburb quick quote form, the contact call-back) all post to `/api/quote` → Resend email to hey@sweptcleans.com.au (primary) + optional `LEAD_WEBHOOK_URL` (future Make.com → BookingKoala lead), sent independently; success only if one confirms delivery (see `docs/LEAD-WEBHOOK.md` – payload version 1, only ever add fields). Name, phone and email are required on every quote form (front end and server); the call-back form is phone-based. Never create placeholder emails. `/login` is noindex and out of the sitemap; the retired `/book-now` (and `/book`) is a single 308 to `/quote?service=regular-house-cleaning`, keeping the query string.
- Quote-only: Swept publishes **no prices** (no packages, rates, "from" prices, estimates or price/offer structured data) – every clean is quoted personally. Every CTA is **Get a free quote** → `/quote?service=…` (service, and on the regular cleaning frequency cards `frequency`, preselected; `?type=commercial` opens the Commercial tab). Customer-facing cleaning types map to the 7 existing services in `CLEANING_TYPES` (`src/lib/quote.ts`); window cleaning and commercial carpet/window cleaning are not offered until the owner confirms them. The regular cleaning page's `#prices` section shows weekly/fortnightly/monthly cards (`src/lib/regularCleaning.ts`). Use `CtaLink` / `primaryCta()` – never hard-code. `npm run test:cta` checks every CTA, the redirects, both tabs end to end and that no Swept price appears outside the educational guides (whose market price ranges stay unchanged).
- Analytics: Google tag `GTM-MFN3G8TW` (GA4 `G-WX83B5MFH0`) via `src/components/Analytics.tsx`, production domain only, Google's snippet unchanged (never add a `gtm.start` push – it double-counts page views). Send events only with `track()` from `src/lib/analytics.ts` (gtag; queued until the container loads); never put personal data in parameters (names, emails, phones, addresses, business names, free text); phone/email clicks are tracked once by `AnalyticsListeners`. `generate_lead` fires exactly once per successful enquiry; `booking_request`/`booking_cta_click` are retired. See `docs/ANALYTICS.md`.
- After changes, run `npm run build`, start on port 3100 with `LEAD_DEV_LOG=1`, then `npm run test:smoke`, `BASE=http://localhost:3100 npm run test:seo` `BASE=http://localhost:3100 node scripts/bookingkoala-check.cjs` and `BASE=http://localhost:3100 npm run test:cta` – or `npm run test:all` (each suite on a fresh server, including the BookingKoala lead form suite, the two webhook payload compatibility suites and the simulated-Resend delivery suite); `npm run test:native` runs them all against the site's-own-form build. `node scripts/compare-sites.cjs` compares two deployments page by page. See `docs/LAUNCH-READINESS-REPORT.md`.
- Service × area pages (`/services/<service>/<area>`, 28 pages) are written per combination in `src/lib/serviceAreas.ts` (intro, local notes, FAQs, description). They target "hire" searches and link to the area guides for prices – never repeat guide prices there. Suburb local facts live in `src/lib/suburbLocal.ts`.
- Don't change the homepage, branding, forms or lead API unless asked.
- Chrome on iPhone has a header workaround (`html.crios` in `globals.css` and `layout.tsx`). Leave it in place until Chrome fixes the iOS 26 bug.
